# 架構與行為

## 邊界

`OkiruCore` 不依賴 UI、Vision、AlarmKit 或翻譯。主 App 負責協調平台副作用；限制擴充套件只讀寫 App Group 政策，不開相機、不嘗試強制啟動主 App。

| 元件 | 職責 |
| --- | --- |
| AlarmDefinition / AlarmOccurrence | 定義與不可回寫的某次排程快照；ID 為鬧鐘 UUID + 預定絕對時間 |
| ScheduleCalculator | 每週當地時間、單次絕對時間、DST 與修改生效時間 |
| ReminderPlanner | 主鬧鐘優先；48 筆產品預算內，按時間排序有限追加提醒 |
| AppModel | 開啟／編輯／完成／解除後核對、持久化、恢復與錯誤呈現 |
| AlarmScheduler | 17/18 本機通知；26+ AlarmKit；26.0 舊版 Alert initializer |
| CameraController / PoseCounter | 串行擷取、15 fps Vision、肩膀與手臂判定、逐影格判定診斷與完整動作計次 |
| AudioController | App 前景音效維持播放器音量 1.0；中斷處理；無法更改系統音量或靜音開關 |
| RestrictionCoordinator / SharedRestrictionStore | Device Activity 排程、例外交集、終止條件與跨程序一致性 |
| HistoryRepository | SwiftData JSON 快照與操作事件，save 失敗 rollback |
| FeedbackService | 有效欄位、20 秒間隔、草稿、UUID 去重、明確 ok:true |

## 三種獨立狀態

1. 系統提醒：已登記／失敗／當次停止。不能據此推定任務成功或實際聽到聲音。
2. 任務：未開始 → 進行中 → 該鬧鐘設定的 5–100 下完成，或緊急解除。5–45 下為五分鐘、50–100 下為十分鐘，從第一次預定時間算起；試做固定十下。
3. 限制：到開始時間生效；完成任務後另等所選 15–120 分鐘，再由 Device Activity 擴充套件解除。三小時催醒結束不解除限制，重疊窗口仍各自有效。

重複完成回呼不改寫首次完成時間。滑掉通知的 delegate 分支只結束處理，不修改任務或限制。前景提示與有限預排的背景追加通知不同；iOS 不保證每三秒實際送達。

## 排程與失敗

- 單次通知保留絕對時區；每週主鬧鐘不依賴再次開 App 才延續。追加通知只承諾當前系統登記的範圍。
- 先做權限／容量前置檢查，移除自己的舊追加提醒釋放預算，再保留主鬧鐘及追加提醒；重新讀取 pending requests 驗證。
- 編輯／刪除不移除已生效限制的任務快照；必要時以穩定衍生 ID 保留原本的一次主鬧鐘。使用者明確將鬧鐘切為停用時，取消該鬧鐘的未完成任務、提醒、首頁下一個鬧鐘及限制；其他鬧鐘維持原狀。
- 編輯失敗嘗試還原舊平台排程。平台不是資料庫交易，仍有部分成功與還原失敗的可能；介面明示 recovery error，列為真機故障注入驗收項目。
- 最近期間依曆日篩選，當日第一鬧鐘不因部分日時間截斷而被第二個取代；歷史顯示保存的時區。
- 完成歷史清除使用 ID tombstone，避免共享儲存把已清紀錄匯回。

## 共享政策

App Group 檔案在 `NSFileCoordinator` 寫入協調區中執行 read–modify–write，使用 atomic write 及首次解鎖後可讀的檔案保護。Monitor callbacks materialize 應發生的限制事件；政策例外取所有有效窗口的交集。所有 shield 寫入只使用 `okiru.restrictions` 命名 store。

Device Activity 的回呼時機、重啟後恢復、撤權與背景狀態並不因模擬器編譯成功就成立，仍須真機驗證。讀取政策失敗時不以「空政策」清除已有 shield。

## 姿態辨識

目前實際門檻集中在 PoseConfiguration：上位手肘 140°、下位 90°、肩膀下降至少 0.90 倍上臂長度、返回時下降至多 0.20 倍、關節信心至少 0.20、姿勢穩定 0.12 秒、完整循環至少 0.65 秒、追蹤掉點容忍 0.75 秒。手肘與肩膀 Y 分別以 0.35 舊值＋0.65 新值平滑。必須經過「上→下→上」才計一次；沒有獨立的軀幹水平門檻。試做畫面顯示原始與實際判定值、判定階段／原因、門檻和時間，文字 JSON 只暫存在記憶體並須主動匯出。這些仍是技術門檻，不是已驗證的人體量測標準；須依 5 人／30 組真機資料校準。

前鏡頭預覽與 Vision 點都做水平鏡像，直向 9:16。各型號畫面裁切與骨架對齊仍列入真機測試。沒有錄影輸出、相簿權限或上傳影像路徑。

## 首版取捨

完整首版範圍不縮減；先驗證核心風險，再送 TestFlight。未加入登入、雲端同步、付費、分析追蹤或貪睡倒數。正式產品不能以無限通知或不可繞過限制作為宣傳。
